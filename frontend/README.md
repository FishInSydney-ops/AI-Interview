# 双前端工作区

在项目根执行 `npm ci`，使用 `npm run dev:portal` 和 `npm run dev:admin` 分别启动。
学员入口为 `/`，后台入口为 `/admin/`；各自 Vite 将 `/api` 同源代理到 `127.0.0.1:8000`。

两端独立路由和 Pinia 根状态。`shared` 只共享类型、请求工具、样式与不持有身份的组件，避免账号域互相污染。
本次业务页为明确标注的预留页，尚未实现登录、CRUD 或练习流程；不使用 mock 数据制造业务完成状态。
生产构建为两个独立 dist，未来正式部署需配置各自的 SPA fallback 与 API 反向代理，不能将 Vite 开发服务用于公网部署。

管理端现有基本布局：深色240px分组导航，可折叠为64px；64px白色顶栏、页面标题、管理员下拉和浅色内容区。按原型提供4组11个菜单，所有业务页面当前为空白占位，不请求业务数据。面试题库、用户/角色/日志/设置等菜单作为原型布局占位，不代表首发功能已开放。通知和退出登录尚未接入，显示禁用状态。
