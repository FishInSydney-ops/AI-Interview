## 5. 待确认与开发前门槛

1. **恢复模型**：父级有效时允许逐项恢复批次中的课程或题目；支持仅恢复学科/阶段并保留整批恢复；本次恢复的冲突与并发事务须验证；单独删除课程时路线引用及关联字段如何与批次记录交互。现有部分唯一索引只是防线，不代表并发恢复已经完成。
2. **签名与版本**：令牌字段、有效期、密钥生成及轮换；实际更新版本的事务时机、题目下架再上架、并发提交和版本校验。`answer_revision` 只声明正整数，递增不可回退由应用保障；不允许用客户端提供的版本替代服务端校验。
3. **本机认证安全**：同源代理的监听地址、路径与部署方式、Cookie 的 `Path`/`SameSite`/`Secure`、CSRF 防护；本机 HTTP 与 HTTPS 的实际限制须验证。密码算法、强度、登录锁定与频控阈值需形成具体契约。
4. **接口完整性**：各字段长度、枚举、默认值、数组上限及错误详情需要补齐；首发使用默认头像、不提供上传；首页统计、管理看板等需先确定首发范围及计算口径。已有数据不足的指标不能伪造。
5. **内容与数据生命周期**：单题跨阶段迁移、题目上架人工核验与解析必填规则、已删除用户恢复入口、恢复内容可见性、停用阶段的界面状态；数据库备份及未来迁移方案。
6. **设计验收**：业务流程及需求范围、API 和 SQL 修改须经用户审核；数据库/API 契约细化后，在单独环境进行经授权的建表、约束与事务测试，验证通过并制定迁移/回滚，才能进入实施。静态检查不代替上述验证。

## 6. 当前需求快照

- **已确认结论**：保持现有技术栈与首发边界；本机同源代理；题库详情可查看答案与解析；首发不提供手动掌握、移除和错题统计卡/Top3；单独删除内容可在父级有效时恢复原状态；作答使用签名令牌与递增版本号。
- **待确认清单**：单对象恢复与批次并发冲突、后台频控来源 IP 获取方式及并发验证、题目迁移、输入范围、认证安全和并发方案；其余按第 5 节逐项落实。

- **本轮新增结论**：后台登录采用固定 5 分钟窗口，同来源 IP 每窗口最多 10 次；窗口边界、计数及固定窗口突发特征见 API 文档。来源 IP 可信代理配置及事务并发尚需验证。
