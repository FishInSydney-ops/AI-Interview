# 云枢智学：数据库设计

> 当前技术基线：用户已确认由 SQLite 切换 MySQL 8.4。SQLAlchemy metadata、`scripts/sql/schema.sql` 与初始 Alembic 快照对应当前结构；历史 SQLite 文档和脚本保存在 `docs/history/` 与 `scripts/sql/schema.sqlite.sql`。基础工程已授权实施，业务规则仍按模块验收。

## 1. 规则与约束

- 所有表使用 InnoDB 和 utf8mb4，逻辑引用 ID，不定义物理外键。统一 `BIGINT AUTO_INCREMENT` 主键；跨表的存在性、归属、状态和删除恢复校验由服务端事务负责。
- 时间使用 UTC `DATETIME(6)`，MySQL 会话时区设为 +00:00；API 输出带 Z 的 ISO 8601。学习日仍按 Asia/Shanghai 的自然日计算。应用需保证传入 UTC 时间，数据库列自身不携带时区。
- 会话、登录锁定和频控使用 MySQL 持久保存；Redis 可作可丢失缓存。MinIO 使用已有私有桶 yszx-files，本次不提供上传业务表。
- 业务使用 deleted_at 逻辑删除；进度撤销使用 revoked_at，错题 removed_at 只为历史设计/后续兼容保留，首发无移除入口。作答快照不可因编辑或删除内容而改写。
- 用户名跨删除全局保留；学科/阶段名称仅在有效对象间唯一，恢复冲突追加“（已恢复）”及必要编号。课程按保存的完整 URL 去重，不存 BV。

## 2. MySQL 特有处理

SQLite 部分唯一索引转换为生成列加唯一索引：条件满足时 guard=1，否则为 NULL；组合唯一索引包含 guard。派生列不供前端输入，不是新增业务状态。

课程 URL 长度为 2048，直接 utf8mb4 索引可能超限，因此有效链接使用 SHA-256 生成列唯一。完整 URL 原样保存且采用二进制排序规则，服务端发生重复键时须读取 URL 精确比较；哈希碰撞报冲突，不自动合并。此为物理存储边界，未改变链接参数不同可分别录入的已确认规则。

本次初始结构采用用户名64、名称/昵称128、标题255、哈希255、URL/来源2048、枚举32、频控维度128等存储长度；题干、选项和解析为 TEXT。业务表单限制与密码强度不由哈希列长推导，后续模块实现时继续细化。

## 4. 逻辑关系和唯一约束

学科→阶段→课程/题目；课程与非归属学科通过 course_subject_link 关联，路线通过 route_course 有序引用课程。分集完成以学员/课程/编号唯一。轮次含固定题目清单，同轮同题只保存一次作答；选项快照归属原作答，错题以学员/题目唯一。两端会话分别关联 student/admin_user。上述均为逻辑关系。

- 每学员最多一个未消费且未撤销临时密码、一个 in_progress 练习；有效管理员最多一名。
- 有效学科名称唯一、同学科有效阶段名唯一；有效课程链接派生哈希唯一。
- 同删除对象最多一条未恢复条目；同批次对象唯一；逐项恢复时实体与 restored_at 一致更新，后续整批跳过已恢复项。
- 同路线有效课程和排序号分别唯一；同课有效跨学科关联唯一。排序替换事务须避免中间唯一冲突，不能认为唯一索引替代业务算法。
- 状态和取值由 CHECK 约束：题目 single/multiple/judgment；难度 easy/medium/hard；题目 draft/published/unpublished；课程 published/unpublished；轮次 stage/mistake 与 in_progress/completed/abandoned。选项正确数的跨行校验由业务层完成。
- answer_revision 从1递增，题型/题干/选项/标准答案实际变化须事务递增；掌握重置指纹不含题型，两者不得混用。数据库只约束版本为正数，不能自动确保递增。

## 5. 事务、统计与生命周期

普通会话7天，受限改密15分钟；成功改密本会话重新计算7天、撤销其他会话，普通改密同时撤销未用临时密码。消费临时密码与创建受限会话、改密与会话撤销均须一致提交，尚待认证模块实现。

作答、选项快照、错题和轮次完成须一致提交。同轮同题已有作答直接返回首次结果；不得重复计数。正确率使用全部已判定作答，包含未完成轮次；完整练习和学习日只依据已完成轮次。首发每轮1–10题，零题不创建；内容不可用后零题轮次结束为未完成。三次连续正确自动掌握，已掌握再错仍掌握并累计错误。

分集记录按学员和课程共享，只计算当前编号范围内未撤销记录；减少集数不删除历史。阶段完成至少有一门上架且未删除归属课程、全部这些课程完成及至少一次完整阶段练习。课程不可直接改所属阶段，删除重录不迁移旧进度。阶段禁用仅影响题目/练习，已上架未删除课程仍可访问。

删除批次只记录本次实际变化。可仅恢复学科或阶段、逐项恢复父级有效的课程/题目、或恢复整批剩余内容；冲突回滚本次事务，不撤销之前已成功恢复。课程引用保留但隐藏，恢复后在有效路线重新显示。批次内外恢复、重删、并发和冲突须实现测试后验收。

## 6. 迁移和验证边界

当前代码中24张业务表和 SQL 导出无物理外键，初始 Alembic 版本0001仅支持空业务库。服务启动不会自动建表，迁移不创建管理员、题库或测试业务数据。MySQL DDL不能保证整批事务回滚，迁移中断须检查已有对象并制定恢复方案；禁止默认删表重试。当前初始迁移不提供自动删表降级。

后续变更新增迁移，不改历史快照；SQLAlchemy metadata 和当前结构导出需同步。历史 SQLite 草案仅归档，不作为 MySQL 执行输入。具体目录、命令、测试与真实服务验证见基础工程交付说明。签名令牌、权限、业务统计、数据备份及迁移细节仍需对应模块落地与验收。
