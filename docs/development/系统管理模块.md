预置超级管理员、内容审核、运营人员。内置角色不删除，超级管理员角色不编辑；自定义角色支持新增、编辑权限和删除（存在有效用户时拒绝）。权限目录9组，未开发模块权限仅作预留，不代表相关业务已完成。后台用户单角色，普通管理者不能授予自己没有的权限，不能管理权限高于自己的账号。超级管理员受保护，用户管理不能禁用、删除、改角色或重置其密码。用户名永久保留；用户删除为逻辑删除。

用户编辑、禁用、删除、重置均撤销目标会话；角色授权每次请求实时读取。批量用户操作最多100人，同事务校验，任何一人不满足则全部回滚。角色、用户、设置采用version乐观校验，并通过超级管理员行锁串行化管理写入，防止并发删除角色与分配用户冲突。

临时密码随机生成，24小时有效，仅响应一次，数据库只保存Argon2id哈希。登录成功后原子消费，建立15分钟受限会话；除查询身份、退出、改密外均拒绝。成功改密撤销全部旧会话及临时凭据，轮换当前Cookie为7天普通会话。原密码登录也受must_change_password限制。密码创建/修改8–128字符。

## API

路径前缀 `/api/v1/admin/system`，沿用统一响应、来源校验和管理端Cookie，后端执行权限检查。

| 接口 | 权限与用途 |
|---|---|
| GET /permissions、GET/POST /roles、PUT/DELETE /roles/{id} | 仅超级管理员，权限目录和角色维护 |
| GET /role-options、GET /users、GET /users/{id} | user:view，列表、角色选项与含最近10条日志的详情 |
| POST /users、PUT /users/{id} | user:create / user:edit，资料与角色维护 |
| POST /user-batches | user:disable / user:delete，body={ids,action:enable或disable或delete} |
| POST /users/{id}/password-resets | user:reset，返回temporary_password和expires_at，不缓存 |
| GET /logs、GET /logs/{id} | system:logs，关键词、动作前缀、起止时间及分页 |
| POST /log-exports | system:export，直接下载CSV，筛选同列表，最多10000条 |
| GET/PUT /settings | system:settings，name、description、logo_file_id、avatar_file_id、version |
| POST /files、GET /files/{id} | system:settings，原始图片流上传与预览 |
| POST /api/v1/admin/auth/password | 已认证本人，new_password，普通会话另需current_password |
| GET /api/v1/platform/settings、GET /api/v1/platform/files/{id} | 公开展示，仅公开当前设置引用的图片 |

列表page默认1，page_size默认20最大100；时间筛选必须包含时区，采用左闭右开区间。冲突409包含VERSION_CONFLICT、PROTECTED_RESOURCE、ROLE_IN_USE；权限403，未认证401，无效输入400，存储不可用503。图片最大2MB、长宽不超过2048，PNG/JPEG/WebP解码后重编码PNG，剥离元信息，存私有yszx-files桶；不更改桶策略。未保存的上传文件保留私有，仅授权管理员可预览，暂不自动清理。

日志只追加，实际已实现写操作与成功登录、退出在事务内记录；失败登录记录匿名身份及状态码，不保存密码、请求体或凭据。未开发模块没有虚构日志。CSV转义公式起始字符，含UTF-8 BOM。导出操作自身也入日志。登录失败日志写入异常会记录服务器错误，不能保证存储故障期间的审计完整性。
