#### 安全与频控

> ✅ 已确认纳入本期（架构设计阶段 T6 确认，阈值采纳建议值并定稿）。本节为原需求文档未定义、经确认后补充的能力，覆盖登录、注册、找回密码三类账号操作。阈值统一在服务端实现，前端仅做与之匹配的交互提示（如 60 秒倒计时）；具体阈值不在前端暴露。

| 项 | 内容 |
|---|---|
| 登录失败锁定 | 同一账号连续 5 次密码错误后锁定 5 分钟，锁定期间登录失败并提示「账号已锁定，请 X 分钟后重试」；登录成功后失败计数清零 |
| 验证码获取频控 | 同一手机号 60 秒内仅可获取 1 次（与前端 60 秒倒计时一致）；同一手机号每日最多 10 次，超出提示「今日获取次数已达上限」 |
| 验证码校验限制 | 同一验证码连续校验失败 5 次后立即失效，需重新获取 |
| 接口请求频控 | 登录、注册、找回密码、验证码、AI 面试发起等接口按 IP + 账号双维度限制请求频次，超限返回业务错误码并提示「操作过于频繁，请稍后再试」，不暴露具体阈值 |

| 随机练习 | 打乱题目顺序作答 |

#### 界面

| 区域 | 功能点 |
|---|---|
| 左侧面板 | 返回题库；练习标题（取所选阶段名）；进度条 + 「当前题 / 总题数」；计时器（时:分:秒，记录本次练习用时）；答题卡（题号网格，点击跳题）；「结束练习」 |
| 答题区 | 题型标签 + 题干；选择题按 A/B/C/D… 渲染选项；简答题文本域 + 「提交答案」 |
| 简答批改 | 提交后展示 AI 评分中动画，随后输出评分卡：分数（x/10）、评语、关键点、参考答案 |
| 答案解析 | 「答案解析」卡：结果徽章（回答正确 / 回答错误 / 未作答）+ 正确答案 + 解析 |
| 底部操作 | 上一题（首题禁用）、查看解析、下一题（末题文案为「完成」，点击等同结束练习） |

#### 答题卡状态

| 颜色 | 含义 |
|---|---|
| 白底灰边 | 未作答 |
| 蓝底 | 当前题 |
| 绿底 | 已答 / 判定正确（含简答通过） |
| 红底 | 判定错误 |

#### 规则

- 单选互斥，多选可多选；已批改题目不可修改。
- 简答题得分 ≥6 分记为通过；未提交的简答不可查看解析、不可进入下一题。
- 「结束练习」：存在未作答简答题时提示并自动跳到该题；否则弹出二次确认（含「还有 N 道题未完成」分支），确认后停止计时、清除会话并返回题库。
- 练习进度本地持久化（题序、当前题号、答案、批改状态、AI 评分、已用时长）；再次进入时提示「检测到未完成的练习，是否继续？」，可选「继续」（恢复进度）或「重新开始」（清空并重选模式）。
- 切换题目时，已批改的选择题自动展开解析，已提交的简答题回显评分结果。

**首发练习中途退出（后续确认）**：阶段练习或错题复习未完成整轮时，已提交并判定的单题作答仍计入总体正确率；其中错误作答进入错题本。该轮不计入完整练习次数，也不产生学习日。总体正确率按全部已提交并判定的作答计算，包含未完成轮次中的作答；是否允许恢复未完成轮次及其具体交互另行确认。

**首发练习中题目更新（后续确认）**：学员打开题目后，如果题目发生实质更新并重新上架，未提交的旧答案不予判分；平台提示题目已更新，学员需重新获取当前已上架版本后作答。已提交并判定的历史作答及其快照仍保留。

**首发练习清单（后续确认）**：服务端保存每轮抽取的题目清单及提供给学员的题目版本标识，用于提交前核验版本、防止重复计分；保存清单不代表首发提供断点续练。具体提交校验、并发与失败处理须在实现前确定。

**首发重复提交（后续确认）**：同一轮次同一题目因网络重试等原因重复提交时，系统只计一次，返回首次已保存的判定结果，不重复增加答题数、错误次数或纠正次数；服务端应先校验轮次归属。

**首发练习中题目下架（后续确认）**：学员准备提交时，若该题仍处于下架状态，将该题从本轮移除，未提交的旧答案不判分，本轮题数相应减少；学员完成剩余题目后即可完成本轮。若所有题目均因下架移除、本轮没有已判定作答，则以未完成结束，不计完整练习次数和学习日，并提示“本轮题目暂不可用”。此前已经提交并判定的作答依既定规则保留。其他无法获取题目的原因如何处理待确认。

### 3.6 错题本

| 模式 | 功能点 |
|---|---|
| 统计卡 | 顶部四张统计卡：错题总数 / 待复习 / 已掌握 / 掌握率 |
| 高频错题 Top3 | 顶部展示错误次数最多的前 3 道待复习错题（按错误次数降序），可点入重做 |
| 浏览模式 | 错题卡片：错误次数徽章（高频易错 / 多次错误 / 偶尔错误）、纠正进度「已纠正 N/3 次」、题干、所属分类、最近答错日期、错误次数、你的答案、正确答案；操作：重新做题 / 标记已掌握 / 移除错题 |
| 批量操作 | 勾选后底部滑出操作栏「已选择 N 项」+ 批量标记已掌握 / 批量移除 / 取消选择，均二次确认 |
| 重做模式 | 按待复习错题顺序逐题练习；提交后标出正确与错选并展示解析；每题答对一次「已纠正次数」+1，累计 3 次自动标记为已掌握；支持上一题 / 下一题 / 退出练习 |

**规则**

- 错误等级：错误次数 ≥3 为高频易错，=2 为多次错误，否则偶尔错误。
- **首发题目版本（后续确认）**：错题保留学员答错时的作答快照和历史判定；重做使用当前已上架的题干、选项与答案。题目下架或逻辑删除期间，历史错误记录保留，但暂不可重做。
- **首发已掌握题再次答错（后续确认）**：已掌握的题目再次答错时，保持已掌握状态，仅累计错误次数增加；答错的作答仍计入总体正确率并保留历史快照。待复习题答错时连续纠正次数归零；题目实质修改后的重置规则仍按下条执行。
- **移除错题后再次答错（后续确认）**：移除的错题再次答错时重新显示，历史累计错误次数保留并增加本次错误，连续纠正次数从零重新开始；即使移除前已掌握，也按此规则回到待复习。历史作答快照不变。
- **首发纠正次数重置（后续确认）**：管理员对已上架题目的题干、选项或标准答案作实质修改前先下架；修改完成并重新核验、上架时，该题相关错题的连续纠正次数归零。历史作答快照、历史判定和累计错误次数保留；仅修改解析或内部来源不重置。按连续答对 3 次判定的已掌握状态随纠正次数归零回退；题目变更与正在进行的练习如何协调，待进一步确认。
- **上架内容指纹（后续确认）**：每次成功上架保存题干、选项和标准答案的比较用指纹。重新上架时将最终内容与上次上架指纹比较，只有指纹不同才触发前述重置；编辑后改回原样不触发。首次上架建立基线，不以“缺少上次基线”作为重置依据。题型变化不单独触发掌握状态重置，题型不计入该重置比较指纹；题型变化时的旧页面作答安全校验须独立处理。具体计算规范和异常处理在实现前确定。
- 已掌握错题置灰，不再显示「标记已掌握」按钮。
- 无选项的题目提示「此题暂无可选的答题选项，请自行复习」并展示正确答案。
- 筛选与排序：状态（全部 / 待复习 / 已掌握）、分类、时间（全部 / 近 7 天 / 近 30 天）；排序按最近答错时间倒序或按错误次数倒序。
- 空态：浏览无结果显示「暂无错题」；重做无待复习题显示「没有待复习的错题」+「返回浏览」。

### 3.7 学习路线

| 区域 | 功能点 |
|---|---|
| 选择学科 | 8 个学科卡片（图标、名称、N 门课程），单选切换 |
| 路线头部 | 路线名、适合人群、路线描述；统计：共 N 门课程、总计时长、按列表顺序学习 |
| 路线课程 | 有序课程列表：序号、封面、课程标题、时长、播放量、「去B站学习」（新标签打开 B 站视频页）；不显示课程 BV 号 |
| 分集进度 | 管理员维护课程视频总集数，学员可逐集标记或撤销完成；显示已完成集数 / 总集数。平台记录学员自报状态，不验证 B 站实际播放 |

**课程完成规则（后续确认）**：当一门课程的所有分集均被学员标记完成时，系统自动将其标记为已完成并计入「已学课程」；撤销任一分集后，整课完成状态与对应统计同步回退。该规则替代直接手动勾选整课完成的方案。

**跨路线进度（后续确认）**：同一学员在任一路线标记同一课程的分集进度，在该课程的其他路线中共享。课程唯一归属及跨学科引用不计入引用方阶段完成条件的规则不变。

**首发阶段完成规则（后续确认）**：学员完成归属于该阶段的全部课程分集，且至少完整完成一轮该阶段练习，阶段显示为已完成。已完成阶段的归属课程因撤销分集或增加未完成分集而回退时，阶段状态同步回退；课程重新完成，且原有阶段练习记录仍满足条件时，阶段自动恢复完成。跨学科引用的课程不计入引用方阶段完成条件。阶段完成仅计算当前已上架且未逻辑删除的归属课程；没有符合条件的归属课程时不能判定为已完成，即使已经完成练习。

**课程集数变更（后续确认）**：管理员增加课程总集数时，保留原有分集的完成记录；没有历史记录的新增分集默认为未完成，按新总集数重新计算进度与整课状态。例如，原进度为 20/20，增加至 22 集后变为 20/22，整课状态回退为未完成。减少总集数时，超出当前总数的分集完成记录保留但不计入当前进度；日后恢复集数时，原有完成状态重新生效。

**分集维护约束（后续确认）**：视频分集顺序不会调整，已有分集不会被替换，新视频只追加在合集末尾；平台只维护分集编号，不需要维护每集独立链接或标题。该约束是历史完成状态按分集编号恢复的依据。

**空态**：未选学科「请选择一个学科方向」；学科无路线「该学科暂无学习路线」；课程为空「课程筹备中，敬请期待」。

**首发补充（后续确认）**：学科或阶段逻辑删除时，其归属阶段下的课程随之逻辑删除；其他路线引用共享课程会受影响，操作前须提示。恢复时只自动恢复同一次删除操作级联删除的内容，此前已单独删除的内容保持删除；共享课程恢复后，仍有效的其他路线自动重新显示原引用，此前已单独移除的引用不恢复。具体恢复顺序待确认。被删除的学科名及阶段名允许新记录复用，旧记录恢复名称冲突时，在原名称后追加“（已恢复）”，仍冲突则追加递增编号。课程不展示也不使用 BV 号，按保存的课程链接完全一致判断重复，不处理链接参数差异；批次中旧课程恢复时若链接与有效课程冲突，暂停整个批次恢复，提示管理员先处理冲突。学习日按 `Asia/Shanghai` 自然日计算。同一学员的课程分集进度跨路线共享。管理员生成的临时密码使用一次后失效，暂不设时间期限；原密码在学员成功设置新密码之前继续有效，临时密码使用后必须设置新密码。临时密码使用后、设置新密码前关闭页面时，可继续使用原密码或联系管理员重新生成临时密码；成功设置新密码后，本次改密会话直接进入平台，该学员其他已有登录会话失效，须重新登录。

**首发学员会话（后续确认）**：学员登录会话状态由服务端保存在 SQLite 中，支持区分普通会话与临时密码的受限改密过程；后台账号和登录态仍与学员端独立。普通学员会话从登录成功起固定有效 7 天，到期后须重新登录；普通登录态改密成功后，本次会话从成功时重新计算 7 天。临时密码本身一次有效、不设时间期限；临时密码登录成功后，受限改密会话固定有效 15 分钟，超时后可用原密码或联系管理员重新生成临时密码；改密成功进入平台后，普通会话的 7 天从改密成功时开始计算。具体安全实现细节另行设计。


**首发练习中断规则（后续确认）**：学员每次最多一轮进行中练习；离开后可返回继续，也可手动放弃。放弃时保留已判定作答和错题，但不计完整练习和学习日。若一轮题目全部因下架或题目、所属阶段、学科逻辑删除或所属阶段被禁用而不可作答且没有已判定作答，系统自动将该轮结束为未完成，允许开始新练习，同样不计完整练习和学习日。

**首发题目不可用及普通改密（后续确认）**：题目下架，或题目、所属阶段、学科逻辑删除时，进行中练习对不可作答题采用相同移除规则；学员在普通登录状态下修改密码须输入原密码和新密码，成功后保持本次登录，其他学员会话失效。

**API 阶段本轮确认**：普通登录态修改密码成功后，本次会话的 7 天有效期从成功时重新计算；阶段被禁用时，其进行中练习的未作答题按题目不可用规则处理，全部不可用且无已判定作答则自动结束为未完成。

**API 阶段补充确认**：首发练习最多 10 题，可用题不足 10 题但至少 1 题时按实际数量开始；没有可用题时提示暂无题目，不创建轮次。已从某轮练习移除的题目恢复可用后不重新加入该轮，但可在后续新练习中再次抽到。

**API 阶段补充确认**：首发错题本不提供手动移除入口，仅按已确认规则维护掌握状态；此前移除后的恢复规则保留供后续扩展或处理已有状态。阶段禁用仅影响该阶段题目与练习，其已上架且未删除的课程仍可通过学习路线访问并标记分集进度。

**整体评审新增确认**：首发错题本仅提供错题列表与复习，统计卡和高频错题 Top 3 推迟；题库详情允许查看答案和解析，练习展示接口作答前不返回答案；单独删除的课程、题目及路线需要恢复，若所属阶段或学科已删除，暂停恢复并提示先恢复父级。

**整体评审补充确认**：单独删除课程、题目和路线后恢复为删除前的上架或启用状态；单独删除课程时保留路线引用并暂时隐藏，恢复后在仍有效路线自动显示。练习展示采用服务端签名临时令牌，提交事务校验当前题目版本和轮次归属；版本标识及并发方案尚待细化。

**整体评审本轮确认**：父级学科和阶段有效时，允许逐项恢复由学科或阶段级联删除的课程及题目；首发仅学员账号采用连续 5 次密码错误锁定 5 分钟，后台登录锁定规则另定；游客可查看符合条件的题库详情、答案和解析。

**整体评审本轮确认**：学科和阶段支持仅恢复自身，同时保留整批恢复；按父级顺序恢复后可逐项恢复课程和题目，整批恢复跳过已恢复条目。后台登录使用独立请求频控，不按账号连续密码错误次数锁定；同一来源 IP 每 5 分钟最多 10 次，计数存 SQLite。

**整体评审本轮新增确认**：后台登录同一来源 IP 每 5 分钟最多 10 次，频控计数存 SQLite 并在重启后按窗口继续生效；学员普通登录态改密成功时，撤销该学员尚未使用的临时密码。

**整体评审本轮确认**：后台登录按固定 5 分钟窗口频控，同一来源 IP 每个窗口最多 10 次；请求计数存 SQLite，重启后按窗口继续生效。固定窗口边界处可出现短时突发，来源 IP 与可信代理配置待验证。

**整体评审本轮确认**：首发个人中心使用默认头像，不提供上传；课程录入后不允许直接修改所属阶段。删除旧课程后重新录入将生成新课程，原有学习进度保留在旧课程记录下，不自动转移。
